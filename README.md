- 💼 **Full-time:** System Engineer at Gävle Energi AB — building automation and data pipelines around electricity metering.
- 🏗️ **Side projects:** Running a handful of self-hosted web platforms, including [prishunden.se](https://prishunden.se) — a Swedish PC hardware price comparison site.
- 🔧 **Open Source:** Maintaining public repos, including a Home Assistant Nordpool energy price component and PHP SDK clients for Kivra and Fortnox.
- 🏠 **Business:** Also running Hemtopia, a small property management company.
- 📫 **Contact:** Reach me via [LinkedIn](https://www.linkedin.com/in/gabriel-trosell) or through my [personal site](https://gabrieltrosell.com).

I started out as an electrician, spent years in electrical engineering drawing schematics, and somewhere along the way the side-project programming took over. These days I spend most of my time writing code — full-stack web platforms, Android apps, CLI tools, scrapers, and infrastructure. I enjoy systems thinking: figuring out how all the moving parts connect and building things that actually work reliably.
